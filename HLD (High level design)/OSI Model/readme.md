# OSI Model

## What is OSI Model?

OSI (Open Systems Interconnection) is a **7-layer networking model** that explains how data is transferred between devices over a network.

## 7 Layers of OSI Model

### 7. Application Layer
- Provides network services to applications.
- Examples: **HTTP, HTTPS, FTP, SMTP, DNS**

### 6. Presentation Layer
- Handles data formatting and representation.
- Performs **encryption, decryption, compression, and data conversion**.

### 5. Session Layer
- **Establishes, manages, and terminates** communication sessions.

### 4. Transport Layer
- Provides **end-to-end communication**.
- Handles **segmentation, flow control, and reliable delivery**.
- Protocols: **TCP, UDP**

### 3. Network Layer
- Handles **IP addressing and routing**.
- Determines the path for packets.
- Examples: **IP, Router**

### 2. Data Link Layer
- Provides **node-to-node delivery**.
- Uses **MAC addresses**.
- Data is divided into **frames**.
- Examples: **Ethernet, Switch**

### 1. Physical Layer
- Transmits **raw bits (0s and 1s)**.
- Handles physical transmission of data.
- Examples: **Cables, Fiber Optic, Radio Signals**

## Summary

| Layer | Name | Important Terms |
