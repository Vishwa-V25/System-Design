# Scaling

## What is Scaling?

**Scaling** is the process of increasing or decreasing system resources to handle changes in **traffic, workload, or number of users**.  
It helps maintain **performance, availability, and reliability** as the workload changes.

## Types of Scaling

### 1. Vertical Scaling

**Vertical Scaling (Scale Up/Down)** means increasing or decreasing the resources of an existing server, such as CPU, RAM, or storage.  
The application continues to run on the **same server**.


### 2. Horizontal Scaling

Horizontal Scaling (Scale Out/In) means adding or removing multiple servers to handle increased or decreased workload.
A load balancer can distribute traffic across these servers.

One Server → Multiple Servers
Scale Up → Increase server resources
Scale Down → Decrease server resources
Scale Out → Add more servers
Scale In → Remove servers

Summary

Vertical Scaling → Make the existing server more powerful.

Horizontal Scaling → Increase the number of servers.
